2. What the Service is

Pronuncia is an extension for the Google Chrome browser that lets you practise reading aloud using text from web pages. The text advances as the browser's speech recogniser transcribes the expected words.

What it is not. The Service relies on Chrome's speech recognition, which reports which words it understood and does not produce a phonetic score. It is not a pronunciation assessment tool or a language certification, and must not be used as one. It is forgiving with strong accents and makes mistakes with proper nouns and technical terms.
